# 3D Portfolio Website

A stunning, modern portfolio website featuring 3D animations, smooth scrolling, and interactive elements.

## ✨ Features

- **3D Animated Hero Section** - Rotating 3D cube with floating icon elements
- **Custom Cursor Effects** - Interactive cursor that follows mouse movement
- **Smooth Animations** - Scroll-triggered animations using Intersection Observer API
- **Responsive Design** - Fully responsive across all devices
- **Interactive Cards** - 3D tilt effects on hover for skill and project cards
- **Animated Statistics** - Counter animations for achievements
- **Contact Form** - Functional contact form with validation
- **Dark Theme** - Modern dark design with gradient accents

## 🎨 Design

- Dark color scheme with purple/indigo/pink gradients
- Glassmorphism effects
- Smooth transitions and hover effects
- Mobile-friendly hamburger navigation
- Professional typography and spacing

## 📂 Structure

```
website/
├── index.html      # Main portfolio page
├── style.css       # All styling and animations
├── script.js       # Interactive functionality
└── [images]        # Project images and assets
```

## 🚀 Sections

1. **Hero** - Eye-catching introduction with 3D elements
2. **About** - Personal introduction with animated statistics
3. **Skills** - Technology stack with progress indicators
4. **Projects** - Portfolio showcase with project cards
5. **Contact** - Get in touch form and contact information
6. **Footer** - Quick links and social media

## 💻 Technologies

- HTML5
- CSS3 (Grid, Flexbox, Animations, Transforms)

- Font Awesome Icons

## 🌐 Usage

Simply open `website/index.html` in a modern web browser. No build process or dependencies required!

## 🎯 Browser Support

Works best in modern browsers:
- Chrome/Edge (latest)
- Firefox (latest)
- Safari (latest)

- Desktop: 1200px+
- Tablet: 768px - 1199px
- Mobile: < 768px
